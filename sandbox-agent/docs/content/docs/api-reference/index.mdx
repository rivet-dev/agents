description: "Sandbox Agent HTTP endpoints, request schemas, and responses."

Use the Sandbox Agent HTTP API from any language. The server listens on port `2468` by default.

[Download the OpenAPI specification](/sandbox-agent/openapi.json).

Browse [schemas](/sandbox-agent/docs/api-reference/schemas/) and [authentication schemes](/sandbox-agent/docs/api-reference/authentication/).
