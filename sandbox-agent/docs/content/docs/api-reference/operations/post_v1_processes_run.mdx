`POST /v1/processes/run`

Executes a command to completion and returns its stdout, stderr, exit code,
and duration. Supports configurable timeout and output size limits.

## Request body



Required.

### application/json

```json
{
  "schema": {
    "$ref": "#/components/schemas/ProcessRunRequest"
  }
}
```

Related schemas: [ProcessRunRequest](/sandbox-agent/docs/api-reference/schemas/processrunrequest/).
