`POST /v1/processes`

Spawns a new process with the given command and arguments. Supports both
pipe-based and PTY (tty) modes. Returns the process descriptor on success.

## Request body



Required.

### application/json

```json
{
  "schema": {
    "$ref": "#/components/schemas/ProcessCreateRequest"
  }
}
```

Related schemas: [ProcessCreateRequest](/sandbox-agent/docs/api-reference/schemas/processcreaterequest/).

## Responses

### 200

```json
{

    "$ref": "#/components/schemas/ProcessInfo"
  }
}
```

Related schemas: [ProcessInfo](/sandbox-agent/docs/api-reference/schemas/processinfo/).
