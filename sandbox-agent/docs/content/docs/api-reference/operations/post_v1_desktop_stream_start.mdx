`POST /v1/desktop/stream/start`

Enables desktop websocket streaming for the managed desktop.

## Responses

### 200

Desktop streaming started

Content type: `application/json`

{
  "schema": {
    "$ref": "#/components/schemas/DesktopStreamStatusResponse"
