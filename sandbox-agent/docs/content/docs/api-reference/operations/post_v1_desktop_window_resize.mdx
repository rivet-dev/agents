`POST /v1/desktop/windows/{id}/resize`

Resizes the specified window to the given dimensions.

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `id` | path | Yes | string | X11 window ID |

### Parameter schemas

```json
[
  {
    "name": "id",
    "in": "path",
    "description": "X11 window ID",
    "required": true,
    "schema": {
      "type": "string"
    }
  }
]
```

## Request body



Required.

### application/json

```json
{
  "schema": {
    "$ref": "#/components/schemas/DesktopWindowResizeRequest"
  }
}
```

Related schemas: [DesktopWindowResizeRequest](/sandbox-agent/docs/api-reference/schemas/desktopwindowresizerequest/).
