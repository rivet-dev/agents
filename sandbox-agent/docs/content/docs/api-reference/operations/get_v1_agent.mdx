`GET /v1/agents/{agent}`



## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `agent` | path | Yes | string | Agent id |
| `config` | query | No | boolean | When true, include version/path/configOptions (slower) |
| `no_cache` | query | No | boolean | When true, bypass version cache |
