`GET /v1/desktop/screenshot/region`

Performs a health-gated screenshot crop against the managed desktop and
returns the requested region image bytes.

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `x` | query | Yes | integer |  |
| `y` | query | Yes | integer |  |
| `width` | query | Yes | integer |  |
| `height` | query | Yes | integer |  |
| `format` | query | No |  |  |
| `quality` | query | No | integer |  |
| `scale` | query | No | number |  |
| `showCursor` | query | No | boolean |  |

## Responses

### 200

Desktop screenshot region as image bytes

### 400

Invalid screenshot region

Content type: `application/json`

```json
{
  "schema": {
    "$ref": "#/components/schemas/ProblemDetails"
  }
}
```

Related schemas: [ProblemDetails](/sandbox-agent/docs/api-reference/schemas/problemdetails/).

### 409

Desktop runtime is not ready

Content type: `application/json`

```json
{
  "schema": {
    "$ref": "#/components/schemas/ProblemDetails"
  }
}
```

Related schemas: [ProblemDetails](/sandbox-agent/docs/api-reference/schemas/problemdetails/).

### 502

Desktop runtime health or screenshot capture failed

Content type: `application/json`

```json
{
  "schema": {
    "$ref": "#/components/schemas/ProblemDetails"
  }
}
```

Related schemas: [ProblemDetails](/sandbox-agent/docs/api-reference/schemas/problemdetails/).
