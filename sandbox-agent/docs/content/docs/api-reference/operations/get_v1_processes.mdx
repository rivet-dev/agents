`GET /v1/processes`

Returns a list of all processes (running and exited) currently tracked
by the runtime, sorted by process ID.

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `owner` | query | No |  |  |

### Parameter schemas

```json
[
  {
    "name": "owner",
    "in": "query",
    "required": false,
    "schema": {
      "allOf": [
        {
          "$ref": "#/components/schemas/ProcessOwner"
        }
      ],
      "nullable": true
    }
  }
]
```

Related schemas: [ProcessOwner](/sandbox-agent/docs/api-reference/schemas/processowner/).

## Responses

### 200

List processes

Content type: `application/json`

