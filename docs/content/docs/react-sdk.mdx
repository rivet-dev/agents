- The `useActor` hook connects to the agent by name and key. Once the connection opens, the hook loads the conversation with `getMessages`.
- The `message_update` event streams the reply as text deltas, and `message_end` adds each finished message, including your own prompt. See [Session Lifecycle](/agents/docs/session-lifecycle#events) for every event.
- The `agent_settled` event marks the agent idle once it has finished, after any retry. The `Chat` component switches its button from Send to Stop while the agent works.

## Next steps

- To steer a run in progress, see [Session Lifecycle](/agents/docs/session-lifecycle#steer-follow-up-or-cancel). To handle errors, see [Client SDK](/agents/docs/client-sdk#results-and-errors).
- To send a login token, add `params` to `useActor`.
- To switch models from the UI, call `setModel` on the connection with one of the agent's `scopedModels`.

See [React](/actors/docs/clients/react) in the Actors docs for everything `@rivetkit/react` can do.
