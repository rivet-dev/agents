<Steps>

<Step title="Install">

```sh
npm add @rivet-dev/pi rivetkit
```

</Step>

<Step title="Define the Actor">

<CodeSnippet file="examples/docs/pi/server.ts" title="server.ts" />

Set `ANTHROPIC_API_KEY`. For another provider, change `model` and set its key instead, such as `OPENAI_API_KEY`, `XAI_API_KEY`, or `OPENROUTER_API_KEY`. See [LLM API Keys](/agents/docs/api-keys).

</Step>

<Step title="Add a sandbox">

Pi's file and shell tools run in a sandbox. Without one they are disabled.

```sh
# E2B
npm add @rivet-dev/sandbox-adapter e2b

# Daytona
npm add @rivet-dev/sandbox-adapter @daytonaio/sdk
```

</Step>

<Step title="Send a prompt">

<Tabs>
<Tab title="TypeScript">

<CodeSnippet file="examples/docs/quickstart/client.ts" title="client.ts" />

</Tab>
<Tab title="curl">

```sh
URL="http://localhost:6420/gateway/agent/action"
AGENT="rvt-namespace=default&rvt-method=getOrCreate&rvt-key=user-123&rvt-pool=default"

curl -X POST "$URL/prompt?$AGENT" \
  -H "Content-Type: application/json" \
  -d '{"args": ["Write a Python script that prints the first 20 prime numbers, run it, and show me the output."]}'

curl -X POST "$URL/getLastAssistantText?$AGENT" \
  -H "Content-Type: application/json" \
  -d '{"args": []}'
```

Each action is a `POST` to the gateway with its arguments in `args`. See [Call Action](/docs/api/gateway/call-action).

</Tab>
</Tabs>

The `prompt` action waits for Pi to finish, then `getLastAssistantText` reads the full reply.
