## Choose a harness

Both harnesses keep conversations through sleep, crashes, and upgrades. They differ in what they run and how much of a cut-off run they recover:

- **Pi** (`pi()`) runs the Pi coding agent, with skills, `AGENTS.md`, and one conversation per agent. After a crash, it resumes a run when Pi can continue the transcript. Use it for chats a person drives.
- **Pi Durable** (`piDurable()`, beta) saves each step of a run, including tool calls and tasks your tools launch, and carries a cut-off run on from the last saved step. Use it for runs nobody watches, such as background jobs, and for tools with side effects.

Not sure? Start with Pi. See [When to use Pi Durable](/agents/docs/pi-durable#when-to-use-pi-durable).

<Tabs>
<Tab title="TypeScript">

<CodeSnippet file="examples/docs/quickstart/client.ts" title="client.ts" />

<Tab title="curl">

```sh
URL="http://localhost:6420/gateway/agent/action"
AGENT="rvt-namespace=default&rvt-method=getOrCreate&rvt-key=user-123&rvt-pool=default"

curl -X POST "$URL/prompt?$AGENT" \
  -H "Content-Type: application/json" \
  -d '{"args": ["Write a Python script that prints the first 20 prime numbers, run it, and show me the output."]}'

curl -X POST "$URL/getLastAssistantText?$AGENT" \
  -H "Content-Type: application/json" \
  -d '{"args": []}'
```

Each action is a `POST` to the gateway with its arguments in `args`. See [Call Action](/docs/api/gateway/call-action).

</Tab>
</Tabs>

The `prompt` action waits for Pi to finish, then `getLastAssistantText` reads the full reply.

```sh

curl -X POST "$URL/prompt?$AGENT" \
```

</Tab>

The `prompt` action waits for the run to finish and returns `{ status, text }`. A model error doesn't reject it: `status` is `unanswered`, with Pi's reason. Sending the same `requestId` to the same conversation again returns the first answer.
