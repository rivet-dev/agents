---
title: "Human in the Loop"
description: "Make a tool wait for a person's approval before it acts."
---

A tool can refuse to act until a person approves. The check is in the tool, so the model can't skip it: `deploy` only runs after someone approves that exact deploy.

- Each approval is an `approval` Actor keyed by the session and the version. Its `consume` action returns whether it was approved and resets it, so one approval allows one deploy.
- Without an approval, the tool returns `terminate: true`, which ends the turn instead of letting the model try again. The agent can sleep while it waits.
- The `ApprovalDialog` component shows the request from the `tool_execution_end` event. Approve calls `approve`, then prompts the agent, which calls `deploy` again. Passing `streamingBehavior: "followUp"` queues the answer if the agent is still running.
- Protect the `approval` Actor with [authentication](/docs/authentication) so only approvers can call `approve`.

See [React SDK](/agents/docs/react-sdk) for the rest of a chat UI.
