## Quickstart

<Steps>

<Step title="Create an API key">

Create a Linear user for the agent, or use your own, and a <a href="https://linear.app/settings/account/security" target="_blank" rel="noopener noreferrer">personal API key</a> for it with read and create-comments access.

</Step>

<Step title="Add the route">

```sh
npm add @rivet-dev/pi rivetkit hono @linear/sdk
```

<CodeGroup workspace>
<CodeSnippet file="examples/docs/connectors/linear/server.ts" title="server.ts" />
<CodeSnippet file="examples/docs/connectors/linear/linear.ts" title="linear.ts" />
</CodeGroup>

Run the server with any runtime that serves a fetch handler, for example `npx srvx --import tsx server.ts`. See [HTTP Server](/actors/docs/http-server).

</Step>

<Step title="Set the environment">

```sh
LINEAR_WEBHOOK_SECRET=lin_wh_...
LINEAR_API_KEY=lin_api_...
LINEAR_TRIGGER=@agent
ANTHROPIC_API_KEY=sk-ant-...
```

</Step>

<Step title="Add the webhook">

In Linear's **Settings > Administration > API**, which needs admin rights, create a webhook with the URL `https://<your-worker>/linear/webhook` and the **Comments** resource type. Copy its signing secret. Comment `@agent` on an issue.

</Step>

</Steps>

## How it works

- The route verifies the `Linear-Signature` HMAC against the raw body and rejects deliveries older than a minute.
- Each Linear issue gets its own agent. Every comment with the trigger continues the same conversation.
- The route never answers the agent's own comments, so replies do not loop.
- The route only hands the comment to the agent's `receive` action and returns. The `receive` action schedules `reply`, which prompts the agent and posts the answer as a comment with the Linear SDK. The schedule is saved with the agent, so the reply still runs if the request that delivered the message goes away.
- A message that arrives while the agent is answering waits as a follow-up, and gets its own reply when its run ends.
- The prompt's `requestId` is the comment's id, so a comment that Linear delivers twice runs the agent only once.

## Configure

| Variable | Purpose |
| --- | --- |
| `LINEAR_WEBHOOK_SECRET` | **Required.** Verifies that deliveries come from Linear. |
| `LINEAR_API_KEY` | **Required.** Posts replies as the agent's Linear user. |
| `LINEAR_TRIGGER` | Text that makes a comment start a reply. Defaults to `@agent`. |
| `ANTHROPIC_API_KEY` | **Required.** The agent's model key. For another provider, change `model` and set its key instead, such as `OPENAI_API_KEY` or `OPENROUTER_API_KEY`. See [LLM API Keys](/agents/docs/api-keys). |

## Supported events

| Linear event | Webhook path | What the route does |
| --- | --- | --- |
| <a href="https://linear.app/developers/webhooks" target="_blank" rel="noopener noreferrer">`Comment`</a>, `create` | `/linear/webhook` | Hands the comment to the issue's agent, which replies with a comment. |
