The `@rivet-dev/pi` package runs the [Pi](https://github.com/earendil-works/pi) coding agent in a Rivet Actor. The agent loop runs in the Actor. Pi's file and shell tools run in a separate sandbox.

Each Actor holds one Pi session and saves it in its SQLite database, so a conversation survives sleep and restarts.

## Configuration

The Pi Actor accepts every [`actor()`](/actors/docs/actor-configuration) option except `db`, which Pi uses for the session, and Pi's [session options](https://github.com/rivet-dev/agents/blob/main/packages/pi/src/runtime.ts), such as `thinkingLevel`, `tools`, and `customTools`. It also accepts:

| Option | Description |
| --- | --- |
| `model` | Model for a new session, as `provider/modelId`. |
| `scopedModels` | Models a client may switch to with `setModel`. |
| `apiKeys` | API keys by provider. Defaults to the environment. |
| `providers` | Custom providers, in the shape of Pi's `models.json`. |
| `credentials` | Logins your application stores. See [User Subscriptions](/agents/docs/user-subscriptions). |
| `sandbox` | Where Pi's file and shell tools run. See [Sandboxes](/agents/docs/sandboxes). |
| `settings` | Pi settings for a new session. |
