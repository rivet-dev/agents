`@rivet-dev/pi` runs the [Pi](https://github.com/earendil-works/pi) coding agent in a Rivet Actor. The agent loop runs in the Actor, and Pi's file and shell tools run in a sandbox.

Each Actor holds one Pi session and saves it in its SQLite database, so a conversation survives sleep and restarts.

## When to use Pi

Use `pi()` for chats a person drives, with the Pi coding agent as it is: skills, `AGENTS.md`, the session tree, and Pi's built-in tools. The [React SDK](/agents/docs/react-sdk), [Human in the Loop](/agents/docs/human-in-the-loop), and connector guides use it.

Use [Pi Durable](/agents/docs/pi-durable) when a run has to finish with nobody there to retry it, tools have side effects, or one agent needs many conversations.

To get started, see the [Quickstart](/agents/docs/quickstart).

## Configuration

`pi()` accepts every [`actor()`](/actors/docs/actor-configuration) option except `db`, Pi's [session options](https://github.com/rivet-dev/agents/blob/main/packages/pi/src/runtime.ts) such as `thinkingLevel` and `customTools`, and:

| Option | Description |
| --- | --- |
| `model` | Model for a new session, as `provider/modelId`. |
| `scopedModels` | Models a client may switch to with `setModel`. |
| `apiKeys` | API keys by provider. Defaults to the environment. |
| `providers` | Custom providers, in the shape of Pi's `models.json`. |
| `credentials` | Logins your app stores. See [User Subscriptions](/agents/docs/user-subscriptions). |
| `sandbox` | Where Pi's tools run. See [Sandboxes](/agents/docs/sandboxes). |
| `settings` | Pi settings for a new session. |

`actionTimeout` defaults to ten minutes and `sleepGracePeriod` to 15 minutes.

## Known limitations

- **One session per Actor.** Use one agent key per chat.
- **One run at a time.** `prompt` throws during a run unless you pass `streamingBehavior`.
- **Retries run again.** A retried `prompt` prompts the agent twice.
- **Partial resume.** A cut-off run resumes only if Pi can continue the transcript, and a cut-off tool call isn't repeated. See [Upgrades](/agents/docs/architecture#upgrades).
- **Long retry waits keep the Actor awake.**
- **Replaced sandboxes.** Absolute paths in earlier `bash` commands point to the old sandbox until the session reopens.
- **Pinned Pi version.** Upgrade `pi-coding-agent` by upgrading `@rivet-dev/pi`.
- **Node.js 22.19 or later.**
