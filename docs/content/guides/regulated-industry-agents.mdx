### What we'll build

- A self-hosted Rivet deployment on a network with no internet access.
- A `caseAgent` per case and an agentOS VM per case, both running inside that network.
- Tools that read internal records and documents without copying them anywhere else.
- A single model gateway that is the only allowed egress, with every other outbound route blocked.

### Similar tools

This is the same job as running Amazon Bedrock in GovCloud, Azure OpenAI over private endpoints, or an on-premises LLM stack. On Rivet the agent, its state, and its sandbox all run on your own nodes, so the only traffic that crosses the boundary is the model call you allow.

### Open questions
