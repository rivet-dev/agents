### What we'll build

- A `delegate_to_agent` tool that reads a remote agent card and picks the skill that fits the task.
- A JSON-RPC client that sends `message/stream` and turns the SSE status and artifact events into tool progress.
- A `delegatorAgent` per conversation that saves each remote task id, so it can call `tasks/get` and pick the task back up after it sleeps or restarts.
- A test that delegates to the agent from the [Cloud Agent over A2A](/guides/a2a-cloud-agent) guide and to an agent built with Google ADK.

### Similar tools

This is the same job as `RemoteA2aAgent` in Google ADK, the A2A client in LangGraph, or the A2A agent type in the Microsoft Agent Framework. On Rivet the caller is a durable agent, so a remote task that takes an hour does not hold a request open, and the result lands in the same conversation when it arrives.

### Open questions

- Rivet Agents has no A2A client tool. The card fetch, JSON-RPC calls, and SSE parsing would be written by hand, or with the A2A JavaScript SDK inside a custom tool.
- How the agent authenticates to a remote agent that requires OAuth or an API key listed in its card, and where those credentials live.
