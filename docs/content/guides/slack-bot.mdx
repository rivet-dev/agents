### What we'll build

- A Slack app that answers when someone mentions it in a channel or a thread.
- One agent per Slack thread that keeps the whole thread's history, so follow-up questions have context.
- A webhook route that acknowledges Slack within its three-second deadline and hands the work to the agent.
- Tools that let the agent look things up in your own systems before it replies.

### Similar tools

This is the same job as building a bot with the Slack Bolt SDK, the Vercel Chat SDK, or the Cloudflare Agents SDK. Here the per-thread state and the long-running reply live in the agent itself, so there is no queue or database to add.
