### What we'll build

- A `fetch` tool that runs inside the agent's agentOS VM instead of on your server.
- `network` permissions on the VM that allow public hosts and deny private ranges, link-local addresses, and cloud metadata endpoints.
- Tests that point the tool at `169.254.169.254`, `localhost`, and an internal hostname and show each one is refused.
- A clear error the model sees when a request is denied, so it can explain the failure instead of retrying.

### Similar tools

This is the same job as following the OWASP SSRF guidance by hand, Cloudflare Sandbox SDK egress controls, or E2B network policies. On Rivet the check runs in the agentOS kernel after DNS resolution, so a hostname that resolves to a private address is denied too.

### Open questions

- `agentOSProvider` in `@rivet-dev/sandbox-adapter` has no option for the VM's `network` permissions. The guide would set them on the VM another way, such as `v1.config.set`, or wait for an option.
