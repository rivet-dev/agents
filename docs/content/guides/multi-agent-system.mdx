### What we'll build

- An `orchestrator` agent per job that breaks the task into subtasks and keeps the plan and the collected results.
- An `ask_specialist` tool that starts one `researcher` subagent per subtask, runs them in parallel, and waits for every answer.
- A `request_review` tool that hands the combined result to a `reviewer` agent with an agent-to-agent message and does not wait.
- Recovery after a crash, so a finished subtask is not asked again and an unfinished one is picked up where it stopped.

### Similar tools

This is the same job as handoffs in the OpenAI Agents SDK, LangGraph multi-agent graphs, CrewAI crews, or Mastra agent networks. On Rivet every agent is its own Actor with its own conversation and tools, so the orchestrator calls a specialist by key like any other Actor, and each one survives restarts on its own.
