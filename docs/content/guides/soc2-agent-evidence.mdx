### What we'll build

- A `sessionAgent` that records each tool call, approval, and model call with the user, time, and result.
- A human approval step for risky tools, with the approver's identity saved next to the call it allowed.
- An `evidenceExport` workflow that forwards those records to Datadog or Splunk and retries until each batch lands.
- Evidence files written to a store your auditors can read, grouped by session.

### Similar tools

This is the same job as Vanta, Drata, or LangSmith audit trails. On Rivet the record of a session lives in the agent's own Actor, so it is written in the same place the work happens, and a durable workflow ships it out without losing events on a crash.

### Open questions

- Rivet has no built-in export of agent events to a SIEM. The guide would collect events with extension hooks such as `afterTool` and `afterResponse` and send them from its own workflow.
