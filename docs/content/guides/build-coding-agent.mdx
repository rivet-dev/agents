### What we'll build

- A `codingAgent` on Rivet Agents with `CodingTools`, so it can read, write, and edit files and run shell commands.
- One agent per coding session, keyed by session id, that keeps the conversation and the sandbox id in its own state.
- A sandbox for each session from the sandbox adapter, on agentOS by default, or on E2B, Daytona, or Freestyle.
- A chat UI that sends messages and renders the agent's events, such as tool calls and file edits, as they stream in.

### Similar tools

This is the same job as OpenAI Codex, Devin, OpenHands, Cloudflare's coding agent template, or Vercel's open agents template. On Rivet, each session is a long-lived Actor that holds its own history and sandbox id, so a session can sleep and pick up later without a separate database or job queue.
