### What we'll build

- A webhook route that receives new issues from GitHub or tickets from Linear through the connectors and hands each one to its agent.
- An `issueAgent` on Rivet Agents per issue, keyed by repository and issue number, that keeps the plan, the branch name, and the sandbox id.
- A sandbox from the sandbox adapter where the agent clones the repository, makes the change, and runs the tests with `CodingTools`.
- A pull request opened when the tests pass, with review comments routed back to the same agent so it can push follow-up commits.

### Similar tools

This is the same job as the GitHub Copilot coding agent, Cursor background agents, Devin, or OpenAI Codex cloud. On Rivet, each issue is a durable agent that can run for hours, sleep while it waits for review, and wake with its full history when a comment arrives.

### Open questions

- How git reaches a private repository from inside agentOS. Passing credentials through host functions, so the token never enters the VM, needs to be confirmed. E2B, Daytona, and Freestyle can take a token in the clone URL or an environment variable.
- Whether the Linear connector can trigger work on ticket assignment, or only on mentions.
