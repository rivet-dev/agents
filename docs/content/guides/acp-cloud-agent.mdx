### What we'll build

- An `/acp` route that accepts Agent Client Protocol messages from an editor over the network.
- An `agentSession` Actor per session that creates a sandbox with `@rivet-dev/sandbox-adapter` and keeps the session's history.
- Sandbox Agent in that sandbox, running Claude Code, Codex, OpenCode, Amp, Cursor, or Pi behind one HTTP API.
- Editor setup in Zed and JetBrains that points the external agent at your server.

### Similar tools

This is the same job as Zed external agents over ACP, Claude Code over ACP, or Cursor background agents. Here the agent runs in the cloud instead of on the laptop, and the session lives in an Actor, so you can close the editor and reconnect to the same run later.
