### What we'll build

- A `browserAgent` per task that plans the steps and keeps each screenshot and the final result on the Actor.
- A sandbox per agent from `@rivet-dev/sandbox-adapter` on E2B or Daytona, with Playwright and Chromium installed.
- Browser tools for the agent, such as open a page, click, type, and take a screenshot.
- An optional switch to a hosted browser like Browserbase instead of a sandbox.

### Similar tools

This is the same job as Browserbase Stagehand, Browser Use, Vercel Sandbox browser agents, or Cloudflare Browser Rendering. On Rivet the agent owns its browser session and its history, so a long task can sleep between steps and resume with the same sandbox.

### Open questions

- agentOS has no headless Chromium, so the browser cannot run inside agentOS. The guide uses an E2B or Daytona sandbox, or a hosted browser.
