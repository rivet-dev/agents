### What we'll build

- A `query_warehouse` tool that runs SQL with a read-only warehouse role and caps the rows it returns.
- An `analysisAgent` per conversation that keeps the questions, the queries it ran, and the answers.
- An agentOS VM per conversation where the agent writes query results to files and analyzes them with pandas.
- Replies that include the charts and tables the code produced and a short written answer that cites the query.

### Similar tools

This is the same job as Hex Magic, Julius, ChatGPT data analysis, or Databricks Genie. On Rivet the agent runs next to your warehouse with your own read-only credentials, and each conversation keeps its files and history, so a follow-up question can build on the last result.

### Open questions

- Whether matplotlib or another charting library installs and renders in agentOS Python. The docs list pandas and numpy as bundled.
- Python variables do not survive a hosted VM's sleep, so the agent should reload saved files on each turn instead of relying on memory from the last one.
