### What we'll build

- A `reportAgent` per team with a cron schedule, set when the agent is created, that calls `prompt` at the time the team picks.
- Tools that fetch the team's metrics from your APIs and compare them with the last digest the agent saved.
- A digest posted to the team's Slack channel with the Slack connector, or sent by email.
- Thread replies routed back to the same agent, so "why did signups drop?" gets answered with the numbers it already pulled.

### Similar tools

This is the same job as Zapier AI agents, a scheduled workflow in n8n, or Lindy. On Rivet the schedule lives in the team's agent, so the agent that wrote the digest is the one that answers follow-up questions, with every past digest in its history.

### Open questions

- Rivet Agents has no email connector. Sending the digest by email would use a custom tool with a provider such as Resend or SES, and email replies would not reach the agent in the first version.
