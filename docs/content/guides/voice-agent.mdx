### What we'll build

- A media service connection that streams the caller's audio and sends each finished turn as text.
- A route that maps the caller, such as their phone number, to their own `callAgent`.
- A `callAgent` per caller that keeps the conversation, tools, and memory between calls.
- Tools the agent can call during the call, such as booking a slot in your API.

### Similar tools

This is the same job as Vapi, Retell, LiveKit Agents, Pipecat, or Cloudflare Realtime agents. Rivet does not handle audio. The media service does the speech, and the Rivet agent holds what the caller said on every call, so a returning caller picks up where they left off.
