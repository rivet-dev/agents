### What we'll build

- A redaction step that finds names, emails, phone numbers, and account numbers with Microsoft Presidio or a regex pass.
- Stable placeholders such as `<PERSON_1>`, saved with their real values in a `piiMap` Actor per conversation.
- A hook that sends only the redacted messages to the model provider.
- A restore step that swaps the placeholders in the model's answer back to the real values before the user sees it.

### Similar tools

This is the same job as Microsoft Presidio, Nightfall, Lakera, or Protect AI. On Rivet the placeholder map lives in an Actor keyed by conversation, so the same person gets the same placeholder across every turn.

### Open questions

- Rivet Agents has no dedicated pre-model guardrail hook. The `beforeRequest` extension hook can replace the messages of a request, which may be enough for redaction, but this is unverified.
- The `afterResponse` hook can only observe a response, so there is no hook that rewrites the model's answer to restore real values before clients see it.
