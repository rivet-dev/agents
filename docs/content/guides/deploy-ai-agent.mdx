### What we'll build

- A Rivet Cloud project, or a self-hosted Rivet in your own cloud, that your clients connect to.
- Workers on Vercel, Railway, or Kubernetes that run your agents, with LLM API keys set only on the server.
- A backend route that signs users in and issues a scoped JWT that reaches only their own agent.
- Trace export from every agent run to your OpenTelemetry backend.

### Similar tools

This is the same job as running the Vercel AI SDK on Vercel, Cloudflare Agents, AWS Bedrock AgentCore, or LangGraph Platform. With Rivet the agents run on workers you already deploy, and Rivet routes each user to their agent, so you choose the host and keep the keys.
